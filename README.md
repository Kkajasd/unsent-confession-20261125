A two-part micro-confession for make.fun's "Unsent: The Micro-Confession Sprint": a `To:` line naming who the message was meant for, and the unsent message itself — one line, written exactly as it was typed, never sent.

## Run it

```sh
node main.ts
```

The program writes the confession to `/output/entry.txt` (176 characters: a 21-character `To:` line and a 153-character message line).
